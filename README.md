## Getting Started
1. npx create-next-app@latest my-app ==> To Start react App

2. Remove everything from global.css and add  => @import "tailwindcss";

3. check for the tailwind that working or not.

4. go to layput and add ==> so children will change and nav and footer will be the same.
        Nav
        {children}
        FOOTER

5. make folder with the name like 'tour' if you want to route it and create inside page.tsx so it will run. and if you want a randomid then create a page with [id] so it works.

6. go to layout.tsx and change the font and add to poppins.

7. add react icons plugin. npm install react-icons
